**🔐 SAML & OAuth2.0 Auto Tester** — a Burp Suite extension (Montoya API) that auto-detects SAML and OAuth 2.0 / OIDC
requests from Proxy history and runs the full manual pentest battery automatically:

- **SAML (25 cases):** signature stripping, certificate faking, **XML Signature Wrapping XSW1–8**, NameID/attribute/audience/recipient tampering, XXE, XSLT, replay.
- **OAuth 2.0 / OIDC (20+ cases):** `redirect_uri` hijack/pollution, PKCE/state/nonce checks, implicit & hybrid downgrade, `client_id` confusion, and **JWT `alg=none` / signature-strip / claim-escalation**.
- Streams **Vulnerable / Secure** findings with one-click **Send to Repeater**.
